# UML Studio — Software Modeling Learning Website

## Run
1. Extract `UML-Studio-Website.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Choose one of the three UML diagrams, then choose Theory, Drawing, or Project Example.

## Included diagrams
- Use Case Diagram
- Class Diagram
- Sequence Diagram

## Modules
Each diagram contains:
1. Theory
2. Drawing
3. Proper Project Example (Online Shopping System)

This is a static website; it does not require Node.js, a database, or an internet connection.
